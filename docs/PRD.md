# PRD: Mobile Flappy-Style Hyper Casual Game

## 목표
- 모바일 웹에서 즉시 플레이 가능한 플래피 버드 스타일 게임을 제공한다.
- 9:16 세로 비율을 강제하고, 원탭 조작과 즉시 재시작이 가능해야 한다.
- 점수 기반 경쟁과 공유 URL을 제공한다.

## 핵심 요구사항
- **플랫폼/기술**: Next.js (App Router), HTML5 Canvas, Vercel 배포 가능.
- **게임 플레이**: 탭하면 점프, 중력 적용, 캐릭터 X 고정, Y만 변화.
- **장애물**: 파이프(상/하) 랜덤 갭, 우측→좌측 이동, 충돌 시 즉시 게임오버.
- **속도 증가**: 점수 증가에 따라 난이도(속도) 상승.
- **점수**: 장애물 1개 통과 시 +1, 실시간 표시, 로컬 하이스코어 저장.
- **게임오버 조건**: 장애물 충돌 또는 화면 상/하 경계 접촉.
- **UI**: 상단 중앙 점수, 하이스코어 작은 텍스트.
- **결과 화면**: 최종 점수, 하이스코어, 재시작 버튼, 공유 버튼 필수.
- **공유 기능**: 점수 포함 텍스트 + `?score=XX` 쿼리 파라미터.
- **공유 링크 진입**: 친구 점수 안내 + "Beat this score" CTA 표시.
- **퍼포먼스**: 60 FPS 목표, 단일 렌더 루프.
- **기타**: 데스크톱 접근 시에도 9:16 비율 유지, 모바일 우선.
