# PRD: Canvas 2D Infinite Runner (Next.js App Router + TypeScript)

## 개요
- Next.js App Router + TypeScript 기반의 Canvas 2D 인피니트 러너 게임을 구현한다.
- Vercel에서 바로 빌드/배포 가능한 프로젝트 구조를 제공한다.

## 핵심 요구사항
- 상태: READY / RUNNING / GAME_OVER
- 점수/가속/코인/장애물/충돌 처리
- Game Over 및 재시작
- highScore는 localStorage에 저장
- 모바일 터치와 스페이스 키 점프 지원

## 배포/품질
- Vercel에서 빌드/배포 가능해야 함
- Next.js App Router 구조 준수
