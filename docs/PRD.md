# PRD: Canvas 2D Infinite Runner (Next.js App Router + TypeScript)

## 목표
Next.js App Router + TypeScript 기반의 Canvas 2D infinite runner를 구현한다. 모바일 터치와 스페이스 점프를 지원하고, READY/RUNNING/GAME_OVER 상태, 점수/가속/코인/장애물/충돌/Game Over/재시작/highScore localStorage를 포함한다. Vercel에서 바로 빌드/배포 가능해야 한다.

## 핵심 요구사항
- Canvas 기반 2D 러너 게임
- 상태: READY / RUNNING / GAME_OVER
- 점수, 가속, 코인, 장애물, 충돌, Game Over, 재시작
- highScore는 localStorage 저장
- 모바일 터치 + 스페이스 점프 지원
- Vercel 빌드/배포 가능
